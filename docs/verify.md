# Verify Stall’s contract documents

CONTRACT.md owns acceptance and status. Generate the tiered acceptance document and homepage claim status before locking the edition:

```sh
node src/base/contract-docs.mjs write
node src/base/contract-docs.mjs id-map --old <main-sha>
node src/base/contract-docs.mjs coverage check --old <main-sha>
node src/base/contract-docs.mjs check
node scripts/edition-authoring/cli.mjs lock
node scripts/edition-authoring/cli.mjs check
```

Public commerce verification remains in the existing Verify wall. Its API journeys use real migrated shop and stock Workers, with fakes only at external network edges; its emitted browser journeys cover desktop and phone. A local response, screenshot or build is not a live provider, delivery, capacity or certification receipt. See the Field proof register for the corresponding proof boundaries.

A historical capability inventory in CHANGELOG.md records the pre-normalization judgment. It does not override the current source. The carried-done audit identifies assertions only in each source clause’s inherited Evidence files; assertions in a helper not listed there cannot keep a clause done.
