# Stall first release

The user jobs are in ACCEPTANCE.md. The shop's own native roles guard every desk, import and data endpoint; signed provider events and public checkout are explicit external doors. Agents prepare drafts and a person approves their exact revision. Pier owns stock and dispatch; Stripe owns card processing. Stall records exact-cent money and immutable approval/provider references.

HTTP-001: the emitted Worker serves health, assets, shop documents and real 404s. The RER operations contract, including migrations, local sign-in, deployment and portability, is SEED-COMMAND-CONTRACT.md. Tests never run as part of build or deploy.

The installed `/` is the Lobby. `rer build --site` emits Stall's independent
marketing homepage, `/run`, and `/docs` from the Markdown in `docs/`. Its Run
actions lead to `/run`; publishing remains disabled until the domain exists.

The desk keeps products, orders, imports, provider connections, activity and
owner data controls on one page. Hash links identify the current section.
Order summaries open the complete shipping/refund record. Statuses use human
labels; operator names resolve from native accounts. Business times use
Australia/Perth, declared in `src/stall/ui/presentation.tsx`.
